## サーバー環境変数
OPENAI_API_KEY / ADW_AI_MODEL / ADW_FIT_CATALOG / ADW_ALLOWED_ORIGIN / ADW_DAILY_LIMIT。
既定はAPI無効。プレビューはローカルのみ。店舗が利用するにはHTTPS接続、実配置先に合ったCORS・認証設計が必要。現在は同一オリジンのみ許可する設計で、BASEへの単純コピーでは動かない。

回数制限は単一プロセス・メモリ内の補助制限であり、再起動時にリセットされる。公開前には永続的な利用制限、費用監視、ボット対策、リバースプロキシに合わせたIP管理が必要。OpenAIへの送信同意を画面で取得する。store:false は提供元の全保存がゼロという意味ではない。プライバシー表示も確認する。
